> 「Cells. Interlinked.」——建站自检完毕，开始记录。

这个博客诞生于一个非常简单的念头：我想要一个**完全由自己掌控**的角落。没有推荐算法，没有点赞数，没有「猜你喜欢」——只有文字本身，和一条稳定的信号。

## 技术选择：回到手工时代

我没有用任何框架。整个站点是**纯 HTML + CSS + 原生 JavaScript**，理由有三条：

1. 零构建：写完直接扔进仓库，[GitHub Pages](https://pages.github.com/) 即刻生效；
2. 零依赖：不追版本号，十年后依然能打开；
3. 零负担：文章就是 `.md` 文件，想改哪里改哪里。

文章清单是一个 `posts.json`，渲染器是一个手写的迷你 Markdown 解析器。全部代码加起来只有几百行，全部可读、可改：

```js
// 发布一篇新文章只需要两步:
// ① 把 Markdown 文件放进 posts/ 目录
// ② 在 posts.json 里登记一条记录
{
  "title": "文章标题",
  "date": "2049-01-01",
  "file": "2049-01-01-slug.md",
  "tags": ["标签一", "标签二"]
}
```

## 关于「维护」这件事

静态网站最容易被忽略的优点，恰恰是它的**长寿**。动态系统需要持续喂养，而静态文件只需要躺在那里，等一位读者路过。

- 没有数据库会腐坏
- 没有运行时会被迫升级
- 没有账号系统会被拖库
